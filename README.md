# الحركة — نظام إدارة حركة المعدات والمشروعات والسائقين

تطبيق سطح مكتب يعمل بالكامل دون إنترنت على جهاز واحد بنظام Windows. يدير المعدات والمشروعات والسائقين، والوقود والصيانة والمصروفات والوقت الإضافي والإهلاك، ويوفر لوحة تحكم وتقارير PDF وExcel.

- **الواجهة**: Angular، بالعربية ومن اليمين لليسار، بتصميم أبيض وأسود.
- **الخادم المحلي**: ASP.NET Core على .NET 10، ويستمع على `127.0.0.1` فقط.
- **قاعدة البيانات**: SQLite عبر EF Core، وتُطبَّق ترقيات القاعدة تلقائياً عند التشغيل.
- **التقارير**: PDF عبر QuestPDF بخط IBM Plex Sans Arabic المضمَّن، وExcel عبر ClosedXML.
- **التغليف**: برنامج `El7arka.exe` يشغّل الخادم داخلياً ويعرض الواجهة في نافذة WebView2.

التفاصيل المعمارية والقرارات المالية موجودة في [docs/01-architecture.md](docs/01-architecture.md)، وتقارير المراحل في [docs/02-phase-reports.md](docs/02-phase-reports.md).

## التثبيت للمستخدم النهائي

### الطريقة الأولى: برنامج التثبيت (مُوصى بها)
1. شغّل `El7arka-Setup-<الإصدار>.exe`. لا يحتاج صلاحيات مدير، ويُثبَّت في `%LocalAppData%\Programs\El7arka`.
2. اترك خيار **إنشاء اختصار على سطح المكتب** مفعّلاً.
3. افتح البرنامج من اختصار **الحركة** على سطح المكتب.

### الطريقة الثانية: النسخة المحمولة (zip)
1. فك ضغط `El7arka-<الإصدار>-portable-win-x64.zip` في أي مجلد، مثل `D:\El7arka`.
2. شغّل `Create Desktop Shortcut.cmd` مرة واحدة لإنشاء اختصار على سطح المكتب.
3. شغّل `El7arka.exe` أو الاختصار.

### أول تشغيل
- **المستخدم**: `admin`
- **كلمة المرور**: `admin123`

سيطلب النظام تغيير كلمة المرور فوراً. بعدها أكمل بيانات الشركة والشعار من **الإعدادات ← بيانات الشركة**.

### المتطلبات
- Windows 10 أو 11 بنظام 64 بت.
- لا يحتاج تثبيت .NET، فالبرنامج مستقل بذاته.
- **WebView2 Runtime**: مثبَّت مسبقاً على Windows 11 ومعظم أجهزة Windows 10. إن لم يكن موجوداً يفتح النظام في المتصفح الافتراضي تلقائياً، وتظهر أيقونة بجوار الساعة لإغلاقه.

### مكان البيانات
كل البيانات في `%LocalAppData%\El7arka\`، ولا تُحذف عند إلغاء تثبيت البرنامج:

| المجلد | المحتوى |
|---|---|
| `data\fleet.db` | قاعدة البيانات |
| `attachments\` | المرفقات والصور والشعار |
| `backups\` | النسخ الاحتياطية (يمكن تغييره من الإعدادات) |
| `logs\` | سجلات التشغيل والأخطاء |
| `webview\` | بيانات نافذة العرض |

### النسخ الاحتياطي
- **يدوياً**: من **الإعدادات ← النسخ الاحتياطي ← إنشاء نسخة الآن**، أو نزّل ملف النسخة واحفظه على فلاشة.
- **تلقائياً**: نسخة كل 24 ساعة. عدد النسخ المحتفَظ بها قابل للضبط، ولا تُحذف النسخ اليدوية أبداً.
- **الاستعادة**: يأخذ النظام نسخة من الوضع الحالي أولاً، ثم يستبدل قاعدة البيانات والمرفقات، ثم يطلب تسجيل الدخول من جديد.
- **النقل لجهاز آخر**: ثبّت البرنامج على الجهاز الجديد، ثم استورد ملف النسخة واستعده من نفس الشاشة.

## للمطورين

### المتطلبات
- .NET SDK 10
- Node.js 22 أو أحدث (لبناء الواجهة فقط)
- Inno Setup 6، وهو اختياري لبناء برنامج التثبيت: `winget install JRSoftware.InnoSetup`

> إن لم يُعرف أمر `dotnet` في نافذة طرفية مفتوحة قبل تثبيت الـ SDK، افتح نافذة جديدة أو نفّذ:
> `$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')`

### التشغيل أثناء التطوير
```powershell
# 1) بناء الواجهة إلى src/Fleet.Api/wwwroot
cd src/Fleet.Web; npm ci; npx ng build; cd ../..

# 2) تشغيل الخادم في المتصفح (بيئة Development + بيانات تجريبية)
dotnet run --project src/Fleet.Api --launch-profile http
# ثم افتح http://127.0.0.1:5080

# أو تشغيل تطبيق سطح المكتب (بيئة Production، على مجلد البيانات الافتراضي)
dotnet run --project src/Fleet.Desktop
```

- في بيئة **Development** تُضاف بيانات تجريبية تلقائياً إذا كانت القاعدة فارغة. البيانات التجريبية أكوادها تبدأ بـ `DEMO-` وأسماؤها تنتهي بـ «(تجريبي)». أوقفها بضبط `Fleet:SampleData=false` في `appsettings.Development.json`. لا تُضاف أي بيانات تجريبية في الإنتاج.
- لاستخدام مجلد بيانات منفصل أثناء التطوير: `$env:Fleet__DataRoot = "D:\el7arka-dev-data"`.
- **Swagger** متاح في التطوير فقط على `/swagger`.

### الاختبارات
```powershell
dotnet test Fleet.slnx
```
- `Fleet.Domain.Tests`: حسابات الوقود والإهلاك والإيجار والوقت الإضافي وتوزيع التكاليف.
- `Fleet.Api.IntegrationTests`: سيناريوهات كاملة عبر الـ API، منها مطابقة التقارير للوحة التحكم، والنسخ والاستعادة، والصلاحيات.

### بناء نسخة التوزيع
```powershell
powershell -ExecutionPolicy Bypass -File build\publish.ps1
```
يبني الواجهة، ويشغّل الاختبارات، وينشر `Fleet.Desktop` كنسخة مستقلة لـ win-x64، ثم يُخرج في مجلد `artifacts\`:
- `publish\El7arka\`: المجلد الجاهز للتشغيل.
- `El7arka-<الإصدار>-portable-win-x64.zip`: النسخة المحمولة.
- `El7arka-Setup-<الإصدار>.exe`: برنامج التثبيت مع اختصار سطح المكتب، إذا كان Inno Setup مثبتاً.

الخيار `-SkipWeb` يتخطى بناء الواجهة، و`-SkipTests` يتخطى الاختبارات. رقم الإصدار يُضبط من `<Version>` في `src/Fleet.Desktop/Fleet.Desktop.csproj`.

### بنية المشروع
```
src/
  Fleet.Domain/          الكيانات والحسابات (بدون EF أو ملفات)
  Fleet.Application/     الخدمات والتحقق والتقارير
  Fleet.Infrastructure/  EF Core وSQLite والملفات وPDF/Excel والنسخ الاحتياطي
  Fleet.Api/             الخادم المحلي (FleetApp) ونقاط الـ API
  Fleet.Desktop/         نافذة سطح المكتب (WinForms + WebView2) وتشغيل نسخة واحدة
  Fleet.Web/             واجهة Angular
tests/                   اختبارات الوحدات والتكامل
build/                   publish.ps1، installer.iss، make-icon.ps1
```
